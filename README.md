# rentas.com.ve

Portal gratuito de alquiler residencial para Venezuela. Publicar no cuesta nada, no hay comisiones y el contacto ocurre directamente entre las partes.

**Estado:** planificación cerrada. Todavía no hay código de la aplicación.

## MVP

Cuatro funcionalidades, ni una más:

1. Publicar una propiedad en alquiler de larga estadía, gratis, con precio en dólares.
2. Buscar y filtrar por ciudad, zona, precio y características.
3. Revelar el contacto de WhatsApp del publicador tras el registro del interesado.
4. Vencimiento a los 30 días con aviso automático previo y renovación en un clic.

Ciudades de lanzamiento: Distrito Capital y Maracaibo.
